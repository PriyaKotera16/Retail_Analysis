# 📊 Retail Sales Analysis

## 📌 Project Overview
This project analyzes retail sales data to extract insights into **sales performance, customer purchasing trends, and product profitability**. The goal is to help businesses make **data-driven decisions** by identifying key trends and patterns in the sales data.

## 🔍 Key Objectives
✅ Identify **top-selling products** and their revenue contribution  
✅ Analyze **sales trends over time** to detect seasonality and growth  
✅ Find **underperforming products** and recommend improvements  
✅ Compute **KPIs** like **total revenue, average order value, and profit margins**  

---

## 🛠️ Technologies Used
- **Python**: Pandas, Matplotlib, Seaborn for data analysis & visualization  
- **SQL**: Data extraction & querying for advanced analysis  
- **Excel**: Data cleaning, pivot tables, and exploratory analysis
